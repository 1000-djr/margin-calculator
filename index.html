광고 리포트 다운로드 방법

쿠팡 Wing → 광고센터 → 광고보고서 탭에서 아래 설정으로 다운받아 업로드해주세요.

  • 기간 구분: 일별
  • 보고서 구조: 캠페인 > 광고그룹 > 상품 > 키워드
  • 클릭이 발생한 키워드만 보고서에 포함 체크
주문서 다운로드 방법

쿠팡 Wing → 주문/배송 → 배송 관리에서 주문서를 다운받아 업로드해주세요.
개인정보는 자동으로 마스킹 처리됩니다.

쿠폰 등록 안내

쿠팡 Wing → 프로모션 → 할인쿠폰 관리에서 사용중이거나 사용완료된 쿠폰 내역을 엑셀 양식 혹은 직접 입력을 통해 넣어주세요.
(할인쿠폰 내역은 쿠팡에서 다운로드가 되지않아 엑셀 양식 혹은 직접 입력을 통해 등록해주셔야합니다.)
